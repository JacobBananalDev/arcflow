# Arcflow

Arcflow is a modern full-stack SaaS platform built with:

- Go (Chi)
- PostgreSQL
- Next.js (TypeScript + Tailwind)
- Docker & Docker Compose
- GitHub Actions (CI/CD)
- AWS (Phase 2 deployment)

---

## Architecture

Frontend → Next.js  
Backend → Go (Chi REST API)  
Database → PostgreSQL
